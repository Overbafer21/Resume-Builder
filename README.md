# Resume Builder

Простое desktop-приложение на Java Swing для создания текстового резюме.

## Возможности

- Ввод основных данных кандидата: ФИО, Email, телефон, навыки, образование и опыт работы.
- Генерация резюме в формате текстового предпросмотра.
- Сохранение результата в файл `MyResume.txt`.
- Быстрый сброс всех полей одной кнопкой.

## Требования

- Java 8+
- `javac` и `java` в переменной окружения `PATH`

## Запуск

```bash
javac ResumeBuilder.java
java ResumeBuilder
```

## Структура

- `ResumeBuilder.java` — исходный код приложения.
